# Скорость скачивания

Скрипт несколько раз скачивает файл по адресу и печатает медианную скорость.

## Запуск

Нужны Node.js 22 и `curl`.

```bash
npm start -- https://example.com/large.jpg
npm start -- https://example.com/large.jpg --requests 100 --concurrency 5
```

Адрес должен быть `http` или `https`. `--requests` задаёт число запросов, `--concurrency` — сколько из них идёт одновременно. Если флаг не передан, запросов 100, одновременно не больше 5. Оба значения — целые числа больше нуля.

## Как считается

К каждому адресу добавляется свой query-параметр `cb`, чтобы прокси и CDN не отдали ответ из кэша.

Скорость одного запроса, бит/с:

```text
size_download × 8 / (time_total − time_starttransfer)
```

Время до первого байта в скорость не входит. Из скоростей всех запросов берётся медиана. При чётном числе это среднее двух центральных значений, поэтому один выброс не сдвигает результат.

Напечатанное число — скорость одного потока, пока канал делят до `--concurrency` соединений.

Если запрос падает или время передачи нулевое, скрипт останавливается и медиану не считает.

Рядом печатаются общий объём в байтах и медианное время передачи в секундах. Если это время меньше секунды, скрипт предупреждает, что замер ближе к задержке, чем к ширине канала.

## Единицы

База — бит/с. На печать скорость делится на 1024, пока единица не дойдёт до Мбит/с:

- меньше 1024 — бит/с
- от 1024 — Кбит/с
- от 1024² (1 048 576) — Мбит/с

Делитель 1 000 000 не используется.

## Файл

Нужен файл на несколько мегабайт, который качается несколько секунд. Картинка, которая кончается за доли секунды, снова мерит задержку.

## Ограничения

Скорость зависит от того, где стоят сервера, которые хранят изображение. Близкий узел и далёкий сервер дают разный результат.
